# 쇼핑몰 질문 게시판

**상태(2026-10-21): 쇼핑몰에 만들어 예시 글 8개(공지 1 + FAQ 7)를 올렸고, `/faq/` 맨 아래에서 링크한다. 챗봇 단일 접수 원칙의 예외라 대표 확인이 필요하다**(`DESIGN.md` §6). 확인 전에 링크를 내리려면 `src/config.js` 의 `SHOP_BOARD_PATH` 를 비운다.
시험(답변 이메일·비밀글 열람 등)은 테스트 회원이 있어야 해서 아직 못 했다. 조사 근거는 아래 '확인 안 된 것'.

## 무엇인가
로그인한 회원이 에어컨 설치·세척·사용에 관한 질문을 글로 남기는 쇼핑몰(아임웹) 게시판이다. 접수·견적 창구가 아니다 — 개인 접수는 챗봇·채널톡이 맡는다.
- 주소: `https://shop.baramdaero.com/34`(메뉴 코드 34, 게시판 DB 이름 `질문 게시판`). 쇼핑몰 위쪽 메뉴에는 넣지 않았다 — 메뉴를 한 칸 더하면 헤더 글자가 '…'로 접힌다.
- 로그아웃으로 열면 로그인 화면(`/login?back_url=LzM0` — `LzM0` 는 `/34` 의 base64)으로 **바로 넘어가고**, 로그인하면 게시판으로 돌아오게 되어 있다. 본 사이트 `/faq/` 의 링크를 눌러도 같다(2026-10-21, 내장 브라우저로 확인: 리퍼러는 `https://baramdaero.com/`, 쇼핑몰 로그인 연결 코드는 복귀 주소를 저장하지 않았다 — 쿼리가 붙은 `/login` 은 버린다). **실제로 로그인해서 게시판으로 돌아오는 것은 테스트 회원으로 확인 안 됨.**
- 페이지 설정: `메뉴 숨김` + `이 페이지 검색엔진 차단`(공개 화면 메타 robots 가 `noindex, nofollow`) + 접근 권한 `로그인 사용자` 와 `로그인창 자동 표시`(2026-10-21 게시).

## 쇼핑몰 설정 (디자인 모드 > 질문 게시판 페이지 > 게시판 위젯 우클릭 > 게시판 설정)
- 일반 게시판, 비밀글 = **작성자가 비밀글 선택 가능**, 비밀글 제목은 '비밀글입니다'로 항상 표시, 회원도 비밀번호 입력·비밀댓글·조회 시 비밀번호는 모두 끔.
- 권한: 목록·읽기·글 작성·댓글 모두 **로그인 사용자**(페이지 접근 권한도 같다).
- 작성자 표시 `닉네임 (일부 * 로 표시)`, 대표 이미지 끔, 글쓰기 버튼 항상 표시, 본문 안내문 "질문 내용을 적어 주세요. 이름·연락처·주소는 적지 않으셔도 됩니다. 개인정보가 들어가는 내용은 비밀글로 올려 주세요."
- 처음엔 '항상 비밀글'로 열었다가(2026-10-20) 운영자 예시 글이 다른 회원에게도 보이게 '작성자 선택'으로 바꿨다(2026-10-21). 게시판·입력폼 위젯은 '게시하기' 없이 공개 화면에 바로 반영된다.
- 쇼핑몰 이용약관에는 게시물 관리·게시 중단(권리 침해 요청)·저작권 조항이 이미 있다(제12~14조). 개인정보 처리방침에는 게시판 글 항목을 아직 넣지 않았다 — 필요하면 선택항목 한 줄을 더한다(결정 대기).

## 올리지 않은 FAQ 글 — 원문(`faq.json`)에 근거 약한 문장이 있어서 (2026-10-21 2차 검토)
게시판 글은 `faq.json` 문장 그대로여야 해서(둘이 갈라지지 않게), 근거가 약한 원문은 게시판에 옮기지 않고 보류했다. 아래는 독립 검토 세 명이 지적한 것이며 **원문 자체의 문제**라 `faq.json`(`a`·`chat_a`)을 고쳐야 풀린다. 고치려면 현장 확인이 필요하다.
- `faq-deep-vs-basic`: '열교환기와 송풍팬까지 분리해' — 1-작업기준 B1·B4·A10 은 열교환기를 분리하지 않고 세척가대를 세워 제자리에서 씻는다(`faq-clean-order` '열교환기는 제자리에서'와도 어긋남). `chat_a`·`trust.json` 89행에도 같은 말이 있다.
- `faq-clean-time`: '예약 확정 때 안내드립니다'(확정 3계열 밖의 약속, 표준 작업 시간은 작업 기준 D 빈칸)와 '주변을 덮은 뒤'(작업 기준에 없는 보양 서술).
- `faq-ceiling-check`: '집에서 가늠해 보기' — 조명·환기구 덮개를 떼고 줄자를 넣는 자가 작업 안내에 출처가 없고 안전 문제가 있다. '건물 유형과 준공 연도로 가늠'도 직접 근거가 없다.
- `faq-capacity-rooms`: '거실과 주방이 벽 없이 이어져 있으면 한 공간으로 봅니다'는 출처 없는 자체 기준이고, 뒤의 한국소비자원 문장은 시험실 크기를 '한 공간으로 두고 시험'으로 바꿔 쓴 것으로 읽힌다.
- `faq-price-how`: 표의 '기본 시공'에 '타공'이 들어 있는데 `faq-extra-cost` 는 '벽 타공'을 추가 항목으로 둔다(같은 게시판에서 포함 범위가 어긋남). 추가비용 글과 표도 겹친다.
- `faq-mold-prevent`: 곰팡이 번식을 늦춘다는 효과와 송풍 전기 절감이 출처 없이 자사 문장으로 쓰였다(핵심인 송풍 건조는 제조사 페이지로 뒷받침됨).
- 첫 검토에서 뺀 `faq-clean-live-in`('방수포'·'해당 공간의 에어컨만 정지'·가구 옮기는 주체)과 `faq-clean-order` 의 '방수포' 문장도 같은 종류다.
원문을 고치면 그 글들을 같은 방식으로 올린다(올리기 전에 원문과 해시로 대조한다 — 옮겨 적다 생긴 오타 세 곳을 이 대조로 잡아 고쳤다).

## 확인 안 된 것 (테스트 회원 두 개로)
1. 비밀글을 쓴 회원 본인이 비밀번호 없이 자기 글을 보는지, 다른 회원에게는 내용이 안 보이는지. 안내문은 '비밀글로 올려 주세요'만 적었고 누가 볼 수 있는지는 단언하지 않았다.
2. 운영진 댓글(답변)이 작성자에게 이메일로 가는지(자동 메일 설정 선행) — 공식 문서로 확인된 것은 사이트 안 종 알림뿐.
3. 작성자 표시 마스킹이 실제 회원 글에서 어떻게 보이는지(운영자 글은 `관리자`로 그대로 나온다).
4. 비밀글·공개글의 검색 노출(페이지는 noindex), 요금제의 게시판·글 수 상한.
5. 스팸 방지(Cloudflare Turnstile 연동)는 설정하지 않았다.
6. 로그인 화면에서 실제로 로그인한 뒤 게시판으로 돌아오는지(소셜 로그인 포함).
