# 사진 교체

프로젝트 폴더에서 `npm run photos`를 실행하면 이 컴퓨터의 사진 편집기가 열린다.

1. 원하는 사진 위치에 JPEG·PNG·WebP 파일을 끌어 넣거나 **사진 선택**을 누른다.
2. 사진 설명을 확인하고 **저장**을 누른다. 세척 절차 사진 설명은 단계 제목에서 자동으로 정해진다.
3. 사이트에 공개하려면 변경분을 검토하고 기존 배포 절차로 배포한다. 편집기의 저장은 로컬 저장이다.

40개 위치를 각각 교체한다. 사진은 잘리지 않으며 방향을 보정하고 최대 2048px WebP로 저장한다. 20MB·4천만 화소 이하의 정지 사진을 지원한다.

기존 사진과 수정 전 JSON은 `.photo-editor-backups/`에 보존한다. 원본 공유 이미지는 덮지 않고 `public/media/<위치>-manual.webp`로 저장한다. 백업 파일은 공개 저장소에 포함하지 않는다. 복구할 사진은 백업에서 골라 편집기에 다시 넣을 수 있다.

편집기는 `127.0.0.1:4318`에서만 실행한다. 공개 사이트에는 편집 화면과 업로드 API가 없다. 저장 중에는 다른 도구로 같은 JSON을 동시에 편집하지 않는다.

검증: `node scripts/photo-editor.mjs --self-test`. 임시 폴더에서 저장·백업·원문 보존·입력 거부·재실행 후 유지를 확인하며 실제 사진은 바꾸지 않는다.
