## 이미지 슬롯

- 총 36개: 16:10 17개 / 4:3 9개 / 1:1 10개
- 라우트별: 홈 7 / 세척·관리 14 / 설치 7 / 신축 입주 8
- `SLOTS.md`와 DOM의 식별자·규격 일치, 중복·누락 0
- 현재 빈 슬롯 36개 모두 회색 박스와 중앙 식별자 라벨 노출

`/care/` 증상 카드는 냄새·풍량 저하·송풍구 오염을 남겼다. `물튐·물떨어짐`은 정기 세척 신호보다 배수·고장 진단 성격이 커 제외했다. 정기관리 카드는 여름 직후·겨울·초봄을 남기고, 증상 발생 후 대응과 겹치는 `여름` 카드를 제외했다. JSON 원본은 수정하지 않았다.

- `npm run build`: 통과, 정적 페이지 10개 생성

- 네트워크 오류: 캡처 중 4xx/5xx 0건
