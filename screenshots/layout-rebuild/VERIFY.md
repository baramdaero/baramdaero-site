# 레이아웃 재구축 검증

- 기준: `origin/main` (`5ae36111f85c44e805802a34158cdadbfdc8df5c`)
- 작업 브랜치: `feat/layout-rebuild`
- 측정 뷰포트: 데스크톱 `1440 × 900`, 모바일 `390 × 844`
- 화면 수: 문서 전체 높이 ÷ 뷰포트 높이
- 프로덕션: 기본 빌드, 빈 이미지 슬롯과 부모 이미지 열 미노출
- 촬영 검토: `SHOW_EMPTY_SLOTS=true` 빌드, 빈 슬롯을 회색 식별자 박스로 노출

## 판정

프로덕션 골격은 사진이 없어도 배포할 수 있는 수준의 구조 개선이다. 모바일은 네 라우트 모두 기준보다 짧아졌고, `/care/`와 `/situation/newhome/`은 데스크톱에서도 각각 0.62·0.79화면 줄었다. 라벨칩·헤드라인·명암 구간과 메시지 단위 분리는 빈 상자 없이도 유지된다.

다만 이미지 지배형 목표가 끝난 것은 아니다. 특히 데스크톱 `/install/`과 `/situation/newhome/`은 1열 카피 옆의 여백이 크게 보인다. 현재 브랜치는 촬영 전에도 의미 있는 골격이지만, 최종 시각 밀도와 지그재그 리듬은 `SLOTS.md`의 사진이 채워져야 완성된다.

## 섹션·본문 밀도

프로덕션의 닫힌 상세 영역을 제외하고 공백을 제거한 화면 텍스트를 실측했다.

| 라우트 | 직접 `main > section` 기준 → 프로덕션 | 메시지 블록 | 최대 노출 글자 수 |
|---|---:|---:|---:|
| `/` | 9 → 9 | 5 | 145자 |
| `/care/` | 9 → 6 | 8 | 252자 |
| `/install/` | 6 → 8 | 7 | 182자 |
| `/situation/newhome/` | 9 → 5 | 9 | 182자 |

- `/care/`의 252자는 증상 4카드를 하나의 선택 구간으로 합산한 값이다. 개별 카드는 최대 64자이며 모두 200자 이하다.
- 증상 4개와 계절 4개는 내용 완결성을 우선해 유지했다. 데스크톱 2×2, 모바일 1열이며 `hidden: true`일 때만 해당 항목이 빠진다.
- 그 외 측정 메시지 블록은 200자 이하이다. 긴 기준·절차 원문은 카피를 바꾸지 않고 기존 상세 영역에 유지했다.

## 이미지 슬롯

- 촬영 검토 모드 총 38개: 16:10 17개 / 4:3 11개 / 1:1 10개
- 라우트별: 홈 7 / 세척·관리 16 / 설치 7 / 신축 입주 8
- 정적 슬롯 32개: `src/content/site/image-slots.json`의 `src`·`alt`가 모두 빈 문자열
- 세척 절차 6개: `src/content/site/pricing.json`의 `process[].image`가 모두 빈 문자열
- `SLOTS.md`·레지스트리·검토 DOM 사이 중복·누락·잉여 0
- 프로덕션 DOM의 `data-slot`·회색 플레이스홀더 0
- 정적 슬롯 ID 누락과 잘못된 `src`/`alt` 쌍은 빌드 오류로 처리한다. 레지스트리·세척 절차의 모든 이미지 경로는 `public/media` 내부 실제 파일인지 공통 검사하며, 없는 파일·디렉터리·경로 이탈·외부 심볼릭 링크를 허용하지 않는다.

## 기능·품질 검증

- `npm run build`: 통과, 정적 페이지 10개 생성
- `SHOW_EMPTY_SLOTS=true npm run build`: 통과, 검토 슬롯 38개 노출
- 최종 `dist/`: 프로덕션 기본 빌드로 복원
- 팔레트: 변경된 소스의 신규 색 리터럴 0, 지정 토큰만 사용
- 대비: 4라우트 본문 고정색 표면 248개 측정, 최저 7.10:1, AA 실패 0
- 가로 오버플로: 4라우트 × 2뷰포트 × 2모드 모두 0
- 네트워크 오류: 두 모드 캡처 중 HTTP 4xx/5xx·요청 실패 0
- 스크럽 에셋 없음: poster/frame 요청 0, canvas·manifest·420vh 활성화 0
- 스크럽 정적 높이: 842.6px / 1440, 644.2px / 390으로 각각 1화면 이내
- 챗봇: 페이지 CTA 14개 + 플로팅 진입점 4개, 총 18/18 열림·초기 메시지 확인
- `dist` grep: 사진 요구 0 / 기간 약속 0 / 금지어 1(`제조사 보증`) / 내부 마커 0
- 헤더·챗봇·푸터·로고 구조와 잠긴 카피 원문은 변경하지 않았다.
